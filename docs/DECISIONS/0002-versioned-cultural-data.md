# ADR-0002：传统数据与规则采用来源门禁和不可变版本

- 状态：accepted
- 日期：2026-07-19

## 背景

《周易》文本存在版本与授权差异，专业六爻存在体系/流派差异。模型可以生成看似完整但无法核实的数据；如果直接写入，将使结果不可追溯且可能侵权。

## 决策

生产文化内容只接受来源、版本、授权和审核完整的 `verified` 记录。pending 记录只存在于隔离示例/候选区，不参与产品查询。每条内容携带规定的九个来源字段；规则集另记体系、来源、适用边界和固定案例。历史保存原始输入、`rulesetVersion`、`contentVersion` 和结果快照，升级不覆盖旧记录。

来源不足时的标准交付是接口、Schema、显式非生产示例和缺失报告，不是补全真实数据。

## 后果

优点：文化内容可审计、授权可判断、结果可复现、不同体系可并存。

代价：V1 可能在数据核验完成前保持空 catalog；内容导入需要人工审核和更严格工具链；更正内容需要新版本而非就地修补。

## 防护

Zod 阻止 pending 进入 production catalog；CI 运行数据校验；发布前增加引用、数量、哈希、卦爻完整性和数据库导入对账。任何人不得用占位内容或 AI 输出绕过门禁。

| 编号   | Android / iOS 均需执行                 | 通过条件                                                                                        |
| ------ | -------------------------------------- | ----------------------------------------------------------------------------------------------- |
| DB-001 | 全新安装并打开应用                     | migration 完成、72 条 verified 结构种子可读、无候选数据导入。                                   |
| DB-002 | 起卦三爻后杀进程，再打开               | 原始三枚铜钱和初至上爻顺序恢复，不重新随机。                                                    |

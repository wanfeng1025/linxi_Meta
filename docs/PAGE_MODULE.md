## 信息架构

底部主入口为首页、历史、知识和设置。栈内流程为：

```text
首页 → 问题输入 → 点击起卦 → 结果概要
  └→ 恢复草稿             ├→ 详细解卦
                           └→ 专业排盘状态

历史 → 历史详情 → 当时结果
知识 → 知识详情
设置 → 关于、隐私与风险声明
```

动态页面只接收稳定 `sessionId`；知识详情只接收稳定 `slug`。问题、六爻数组和快照不进入 URL。

## 状态流

```text
启动加载
  → 校验 SQLite migration 和内容版本
  → 检查持久化草稿 / 待落库锁定会话
  → draft
  → collecting（1–5 爻）
  → complete（6 爻，只读）
  → locked（历史事实 + 首个结构快照）
```

草稿保存在现有 `settings` 表的版本化 envelope 中。每次起爻先调用 `CastingService.castNext`，由安全随机端口产生并原子保存三枚铜钱；恢复只读取已保存事实。第六爻完成后需要显式锁定。锁定与历史写入之间若应用中断，envelope 中的 `pendingCompleted` 会在下一次启动补写历史，避免重新随机。

## 能力边界

- 基础结果：使用已核验 8 卦、64 卦显式结构映射；
- 解释结果：没有经核验生产规则时，主象、辅助象、趋势和建议保持未定，页面显示原因；
- 专业排盘：`UnavailableProfessionalChartAdapter` 只返回缺口和已确认字段，不返回伪造爻表；
- 知识库：已核验八卦和六十四卦结构可查看；阴阳五行、干支、六亲、六神、纳甲和世应等未确认正文标记为待审核；
- 设备能力：摇一摇、触觉和音频尚未完成真机验收；设置页不声称已启用。

## 无障碍与视觉

设计系统提供高对比度浅色/深色主题、可调整字体、44–48pt 以上主要触控区、语义角色/标签、非颜色唯一的动爻标识，以及文字化错误与风险提示。太极、篆印红、米纸色和卦线用于视觉识别，但正文对比度与可读性优先。
